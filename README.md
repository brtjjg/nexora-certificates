# Nexora Certificates Portal

Admin-only certificate issuance and verification portal for Nexora Academy.

## Features

- 🔐 Admin login (uses Academy backend auth)
- 🎓 Issue certificates to students (dropdown of students + courses)
- 📋 View all issued certificates with search
- ✅ Public verification page (no login required)
- 🖨️ Printable certificate preview

## Backend

Uses `https://nexora-api-sskg.onrender.com/api`

## Deploy

Hosted on Vercel. Any push to `main` auto-deploys.
